# Статус подготовки публикации

[English version](release-preparation.md)

В первоначальную публикацию исходников от 7 октября 2026 года входят самостоятельный исследовательский снимок, финальные английские условия и включённая конфигурация электронного принятия. При первоначальной публикации проверки не проводились. 7 октября в рамках V10 установка, тесты, сборка и воспроизведение самостоятельного V9 прошли; исполнение workflow передачи прав остаётся непроверенным. Публикация исходников не подтверждает эксплуатационную готовность.

## Что подготовлено локально

- Независимый репозиторий на main с origin nutrifit-health/craving-engine; его вложенный каталог исключён из родительского NutriFit.
- Выбранные синтетические входы, граф, folds, замороженные матрицы признаков и прогнозы GBDT; реальных данных пациентов и регистрационных PDF компании нет.
- Обучение/replay V9 MB, самостоятельный загрузчик, зависимости и выбранные исторические результаты, включая скопированную выдержку для высокой полноты.
- Документация на английском и русском о целях, отрицательном допуске, составе памяти и следующих шагах.
- Финальная английская некоммерческая лицензия и соглашение о передаче прав; active=true в rights-config.json, оба принятых текста сохраняются в квитанциях.
- Шаблоны issues/PR на английском и русском. Фрагменты статьи исключены из публикации.

## Оставшиеся развёртывание и проверки

1. Первоначальная публикация исходников разрешена владельцем. Её ревизия зафиксирована в истории Git репозитория.
2. После отправки в main должны быть доступны GitHub Actions. Нужно сделать NutriFit / contributor rights обязательным статусом перед merge и ограничить обход/прямые push. Локальный YAML не задаёт эти правила репозитория; удалённо они пока не настроены.
3. Установка, применимые тесты, сборка и самостоятельное воспроизведение выполнены по явному запросу пользователя. [Основные метрики V9 совпали с архивом точно](../results/v10/verification/v9-reproduction-comparison.json). Проверка реального workflow передачи прав остаётся отдельной работой.
4. После выпуска зафиксируйте опубликованную версию и фактическое evidence исполнения. Наблюдаемые проблемы переносимости и численные различия устраняйте без перезаписи исторических результатов. Исходный генератор V9, backend-encoder и обучение GBDT не входят в снимок; V10 содержит собственный генератор контролируемых сценариев адаптации.

У исходного запуска V9 есть исторические проверки и отрицательный результат. Для публикации этого исследования успешный кандидат не требуется. Заявление о проверенности выделенного кода или электронного процесса требует evidence именно этих компонентов.
