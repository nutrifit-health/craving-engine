# Публичный снимок протокола V9

[English version](protocol-v9.md)

Этот документ описывает исходный эксперимент V9 и предполагаемое автономное воспроизведение на выбранных входных данных. Это публичное описание методологии, а не доказательство того, что выделенный код запуска воспроизвёл исторический результат. Изменения при подготовке отдельного пакета записаны в `extraction.json`.

## Исследовательский вопрос и фиксированное сравнение

Более широкая цель исследования — полезные предупреждения о срывах диеты с помощью общей модели и индивидуальной памяти пользователя, без обучения полной модели для каждого пользователя. Полнота обнаружения событий около 94% — желаемый целевой уровень чувствительности, а не доля правильных предсказаний (accuracy) и не достигнутый продуктовый результат. Для допуска V9 используется описанное ниже сравнение с ограничением FPR20; рабочая точка с высокой полнотой служит для диагностики и не может отменить отказ в допуске.

Улучшает ли обученное на общей популяции представление на основе грибовидного тела с индивидуальной онлайн-памятью обнаружение синтетических срывов настолько, чтобы обосновать новый слепой тест, по сравнению с фиксированной моделью GBDT и контрольной моделью со скалярной памятью?

Заранее назначенным кандидатом была анатомическая MB с индивидуальной памятью. Сравнивались шесть вариантов: популяционная GBDT, GBDT + скалярная память, популяционная анатомическая MB, анатомическая MB + индивидуальная память, популяционная MB с переподключённым графом и MB с переподключённым графом + индивидуальная память. Варианты с переподключённым графом — контрольные модели, а не альтернативные кандидаты, выбранные после просмотра результатов на выборке разработки.

## Данные

Все истории пользователей синтетические. Обучающая выборка включает 60 пользователей (10,800 решений), калибровочная — 20 пользователей (3,600 решений), выборка разработки — 40 пользователей (7,200 решений); на каждого пользователя приходится 180 ежедневных решений. Пользователи не пересекаются между выборками. Этот набор данных не позволяет установить частоту событий или характер предсказаний для реальных пользователей.

Каждая строка содержит идентификаторы события и пользователя, время решения и доступности данных, наблюдаемую обратную связь и время её поступления, исход для оценки, а также исторические поля, сохранённые для прослеживаемости происхождения. `X` — зафиксированный наблюдаемый контекст из 94 полей; `schema.json` перечисляет имена, единицы измерения, индикаторы доступности и семантику. Выбранный комплект содержит матрицы, а не генератор или исходный кодировщик backend. Изменение исходных записей не приводит к автоматическому пересозданию матриц признаков.

В симуляции вероятность сообщения об исходе зависит от самого исхода (0.8 для положительных исходов, 0.7 для отрицательных), а обратная связь поступает с задержкой 20 часов. Это допущения симуляции, а не наблюдаемые частоты сообщений в NutriFit. Отсутствие обратной связи не считается отрицательным исходом. Из 10,800 обучающих решений у 8,136 есть наблюдаемая обратная связь; доля положительных исходов среди наблюдаемых составляет примерно 58.12%.

Метки для оценки доступны для расчёта метрик по всем решениям калибровочной выборки и выборки разработки, включая события, о которых не поступило сообщений. Это идеализирует возможности измерений в работающем продукте. Метки для оценки исключены из обучения MB и обновлений индивидуальной памяти. При калибровке полный набор синтетических меток для оценки используется только для выбора порогов; он не служит обучающим входом популяционной модели.

## Представление

Анатомический артефакт — подматрица ALPN → KC из MaleCNS v1.0: 164 подключённых ALPN, 2,019 клеток Кеньона с левой стороны, 11,301 взвешенное ребро и 192,391 синапс. Из этих KC у 124 нет входа от ALPN в выбранной подматрице. Другие входы, APL, дофаминовые нейроны, MBON и рекуррентная динамика исключены. Число синапсов задаёт неотрицательные структурные веса; это не экспериментально установленные проводимости и не физиологическое правило обучения.

Для каждого наблюдаемого признака обученное преобразование вычисляет контраст через asinh с учётом маски относительно статистик обучающей выборки, после чего формирует каналы ON и OFF. Пропущенные значения дают нулевые каналы, а индикаторы их доступности остаются отдельными входами. Отображение этих каналов человеческого контекста на ALPN искусственное; seed отображения зафиксирован на 11.

В представлении используются анатомические веса с нормировкой по строкам, положительная top-k активность с долей победителей 5%, RMS-масштаб, полученный на обучающих данных, и якорная координата. Закодированный вектор нормируется по L2. Якорь — координата контекста, относительное влияние которой зависит от нормы контекста; это не отдельно обученная глобальная выходная модель.

В контрольной модели с переподключённым графом используются двойные перестановки рёбер с сохранением степеней вершин и seed 20260923. Они сохраняют бинарную входную степень KC, выходную степень ALPN и мультимножество весов внутри каждой KC. Они не сохраняют суммарный вес выходов ALPN или все мотивы более высокого порядка. Оба варианта графа используют одинаковый инженерный адаптер и процедуру обучения.

## Обучение популяционной модели

MB — самостоятельный популяционный предиктор. Он не получает вероятности GBDT в качестве смещения логита. Выходная модель — бинарная LogisticRegression (`C=10`, `max_iter=2000`, `tol=1e-6`; полный набор параметров находится в `research_v9/types.py`). Ансамбль из трёх моделей, обученных на фолдах без пересечения пользователей, использует сигмоидальную калибровку. На каждом фолде нормировка, представление и выходная модель обучаются на собственных строках обучения; сигмоида использует соответствующих исключённых пользователей. Итоговая вероятность — среднее трёх откалиброванных вероятностей.

В обучение выходной модели входят только строки с наблюдаемыми обучающими исходами, с единичным весом каждой строки и без изменения весов классов. Зафиксированные индексы фолдов и идентификаторы обучающих событий совпадают с историческим сравнением с GBDT. Одинаковые входы и фолды не означают равной ёмкости моделей или одинакового бюджета оптимизации.

Предсказания итогового ансамбля на обучающей выборке не являются полностью внефолдовыми: другие участники ансамбля могли обучаться на данном пользователе. Онлайн-представление отдельно обучается на всём обучающем `X`, включая строки без меток, без исходов для оценки. Оно фиксируется до воспроизведения хронологии калибровочной выборки и выборки разработки.

Публичный код запуска **не переобучает GBDT**. Он использует сохранённые согласованные предсказания для калибровочной выборки и выборки разработки. Он позволяет воспроизвести обучение MB и сравнение с этим фиксированным эталоном, но не полный конвейер генерации синтетических данных и обучения GBDT.

## Индивидуальная память и хронология

Каждый пользователь получает независимое состояние памяти. Популяционная модель и кодирование остаются фиксированными во время воспроизведения хронологии. Память содержит быстрые и медленные веса остаточной коррекции, состояние экспозиции, механизм допуска коррекции на основе знакомости контекста и ошибки, снимки ожидающих событий и историю наблюдений. Значения по умолчанию и формулы заданы в `research_v7/types.py`, `research_v8/types.py` и `research_v8/memory.py`.

При воспроизведении хронологии предсказание выполняется до получения текущего исхода. Событие с наблюдаемой обратной связью обновляет память только тогда, когда время его поступления строго меньше времени следующего решения. Снимки предсказаний сохраняют контекст, использованный при исходном решении. События без наблюдаемой обратной связи не обновляют модель. Каждая выборка и каждое семейство моделей используют собственную память. Опыт пользователей калибровочной выборки не переносится на пользователей выборки разработки.

Итоговая вероятность получается через управляемую механизмом допуска коррекцию в пространстве логитов поверх популяционного предсказания соответствующего семейства моделей. Механизм допуска может подавлять персонализацию, когда доступные данные её не поддерживают; этот механизм не доказывает отсутствие вреда для отдельных пользователей. Полное состояние больше одного вектора весов выходной модели, и его нельзя описывать как измеренный продуктовый бюджет 16 KiB на пользователя.

## Метрики

Основная рабочая точка — `calibration_macro_fpr20`: для каждой модели на калибровочной выборке выбирается порог, который максимизирует макроусреднённую полноту при ограничении макроусреднённой FPR ≤ 0.20. Все шесть порогов и простой базовый вариант фиксируются до расчёта метрик на выборке разработки. Более сильный простой контрольный вариант выбирается между популяционной моделью и моделью со скалярной памятью по полноте на калибровочной выборке; при равенстве используется Brier.

Публикуются макроусреднённые полнота (recall), FPR, AUC, Brier и индекс Юдена J, парные сравнения пользователей, суммарные количества исходов в матрице ошибок и статистика уведомлений. При макроусреднении пользователи имеют равный вес; когда у пользователя есть только один класс исходов, важно учитывать условия включения, специфичные для каждой метрики. Индекс Юдена J = полнота − FPR; он безразмерный и не является долей правильных предсказаний (accuracy). Доверительные интервалы рассчитываются повторной выборкой на уровне пользователей по фиксированной бутстрэп-процедуре реализации.

Ограничения предупреждений оцениваются отдельно от порогов классификатора: не более 2, 3 или 7 предупреждений в скользящем семидневном окне. Полнота классификатора не равна охвату событий предупреждениями. Обнаружение события не доказывает, что предупреждение предотвратило бы его.

## Допуск

По сравнению как с популяционной GBDT, так и с простым базовым вариантом, выбранным на калибровочной выборке, назначенный кандидат должен выполнить все следующие условия:

- прирост полноты не менее 5 процентных пунктов и парный 95% доверительный интервал целиком выше нуля;
- прирост индекса Юдена J не менее 0.02 и парный 95% доверительный интервал целиком выше нуля;
- макроусреднённая FPR не выше 0.20 и её увеличение не более 0.01;
- макроусреднённый Brier не хуже, а суммарный показатель Brier skill относительно доли положительных исходов в обучающей выборке положителен;
- доля пользователей со снижением AUC более чем на 0.01 не превышает 0.05;
- улучшение полноты предупреждений при политике двух предупреждений за семь дней без ухудшения числа ложных тревог на одно обнаруженное событие.

Исходный кандидат не прошёл допуск. На калибровочной выборке простым базовым вариантом была выбрана модель со скалярной памятью. Слепой тест после этого не проводился. Существующие метрики на выборке разработки известны, поэтому будущие изменения, оцениваемые по ним, носят поисковый характер и для подтверждения требуют новой нетронутой когорты пользователей. [Дорожная карта](research-roadmap.ru.md) описывает предлагаемые вопросы для дальнейших исследований; она не заменяет этот исторический протокол и не является предварительной регистрацией следующего эксперимента.

## Сохранение артефактов и изменения для автономного запуска

Исходный эксперимент остаётся в закрытом исследовательском архиве NutriFit. Этот репозиторий сохраняет выбранные исходные входные и выходные данные; хеши исходных входных данных и имена исходных артефактов находятся в `data/v9-frozen/manifest.json`. Манифест выбранных файлов не является манифестом всего закрытого архива.

Автономный код запуска использует отобранный комплект вместо закрытого родительского запуска, сохраняет снимки публичного исходного кода без закрытых метаданных Git и записывает каждую попытку в новый каталог. При выполнении он проверяет согласованность артефактов. Во время выделения пакета не проводились новый эксперимент, установка, тесты или проверка соответствия исходного кода результату.

Выбранный набор результатов также включает `high-recall-excerpt.json` с полями, скопированными из исходного `report.json` без повторного расчёта. Его происхождение записано в `extraction.json`; он отделён от манифеста выбранных входных данных. Статус публикации выделенного пакета описан в документе [«Подготовка публикации»](release-preparation.ru.md).
